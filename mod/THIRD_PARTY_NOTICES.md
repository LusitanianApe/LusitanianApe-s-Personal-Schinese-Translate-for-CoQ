## 三、其它来源

### 1. ★ 矮人要塞国际本地化项目 `dfint`（**方法论借鉴**）

> ★ **性质说明（重要）**：本项目**没有复制 dfint 的任何代码或文本** ——
> 语言（Python/PE-x64 ↔ C#/托管程序集）、被解析对象、运行平台**全都不同**。
> 借鉴的是**「全量提取硬编码文本」的方法与判据**。
> 按 MIT 与常识，**借鉴方法论同样署名**，故列在此。

| 项 | 内容 |
|---|---|
| 项目名 | **dfint** —— Dwarf Fortress localization project（矮人要塞多语言本地化项目） |
| 链接 | <https://github.com/dfint> |
| 具体仓库 | `dfint/dfint64_patch`（本项主体）· `dfint/stringdumps` · `dfint/df-translation-toolkit` · `dfint/generate-resources` |
| 导入版本 | **未固定版本**（仅阅读方法论）。取证日 **2026-10-10**，代码来自其 `master` 分支：<br>`dfint64_patch/extract_strings/cli.py` · `extract_strings/from_raw_bytes.py` · `cross_references/cross_references_relative.py` · `pyproject.toml` |
| 本地文件 | **无**（未下载、未放入本模组；分析笔记见 `_tools\DFCN-可借鉴清单.md` 附录二） |
| 许可 | ✅ **MIT License**（`pyproject.toml` 内 `license = "MIT License"`） |
| 著作权人 | **insolor**（`pyproject.toml` 的 `authors`）及 dfint 项目贡献者 |

**借鉴了什么（具体到判据，便于核对）**：

```
① ★★ **「用代码交叉引用证明字符串是活的」** 这一两阶段思路
     dfint：数据段线性扫候选 → 代码段找 4 字节 RIP 相对引用 → **只留有引用的**
     我方：拟用于「扫全程序集 `ldstr` 得活串全集 → 与元数据堆求差」
     ⇒ 目的是**让死串自动出局**，不再靠人工猜「哪些算候选」
② **「三重边界判据」**（至少一个字母 · 字符集白名单 · NUL 终止 + 对齐）
     ⇒ 可用于把我方「不该译的内部键」从人工逐条判断改为机械判据
③ **「剔除带格式/控制字符的串」**（dfint 排 `$ ^ @`，其中 `$` 是 DF 的颜色标记）
     ⇒ 对应我方应排除的 `=Name=` / `{{…}}` 一类
④ **「提取物按版本独立存档、可重跑」**（`stringdumps` + `generate-resources`）
     ⇒ 对应我方拟做的 `_tools\_census\<版本>.txt`

★ 我方**已有局部先例**（说明该思路在本平台可行，非空想）：
   `Scripts\ZhsEffectDetailsPatch.cs` 的 `DumpLiterals()` 已在读 IL 字节码取 `ldstr`
   （2.16.64：142 个 `GetDetails` 覆盖 → 88 条字面量 → 100% 覆盖）。
```
